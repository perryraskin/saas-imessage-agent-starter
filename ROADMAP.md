# Roadmap

The initial release provides the production boundaries and a safe simulator. The next reusable layers are tracked in GitHub Issues:

- Immediate-value first-conversation onboarding.
- Broader bounded SaaS tool patterns.
- Consent-first proactive check-ins.
- Transparent recovery, timeout, and delivery reconciliation.
- Provider canaries and stronger physical-client regression coverage.
- Maintained PostHog dashboards and alerts.
- More exact-link and privacy-safe OG preview examples.

Roadmap work must stay generic. Product-specific domain tools belong in adopter repositories.
