# Native iMessage quality

Use these rules whenever you compose a channel response:

1. Lead with the result.
2. Prefer one or two short bubbles over a mini-document.
3. Never output Markdown syntax.
4. Put a raw destination URL on its own line.
5. Never claim progress before execution starts or completion before the canonical service succeeds.
6. If a change is reversible, mention “undo that” once after success.
7. If the service fails, state whether anything changed and give one next step.
